ClipFlow（Windows 版）

这是 ClipFlow 的 Windows 版本。它和 Mac 上的版本功能一样：
- 自动记录最近复制的 300 条文字，可以搜索、置顶、点一下复制回去
- 常用片段（snippets）
- 深色 / 浅色 / 跟随系统，以及自定义背景图片
- 每条记录右侧的 AI 按钮（需要先在“设置”里填写自己的 AI 地址和密钥）

怎么打开
1. 先解压整个文件夹（不要直接在压缩包里双击）。
2. 双击 ClipFlow.exe。
3. Windows 第一次可能会提示“Windows 已保护你的电脑”，这是因为程序是本机打包、没有购买签名证书。
   点“更多信息”，再点“仍要运行”即可。

数据存在哪里
设置和记录只保存在这台电脑上：%LOCALAPPDATA%\ClipFlow\state.json
删除这个文件夹就会清空记录。

第一次使用
打开左侧的“设置”（Settings）：
- 外观：深色 / 浅色 / 跟随系统，也可以选一张自己的背景图片。
- 语言：可以在中文和 English 之间切换。
- AI：填入请求地址、模型和 API key，点“测试连接”（Test connection）确认能连上；
  不填也能正常记录剪贴板。
